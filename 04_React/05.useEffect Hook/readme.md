# ⚛️ React useEffect Hook

A simple React project demonstrating the **useEffect Hook** and how it manages side effects in functional components. This project covers component lifecycle behavior, dependency arrays, cleanup functions, and practical examples to help understand when and why `useEffect` executes.

## 🚀 Features

- Understanding `useEffect`
- Component lifecycle with Hooks
- Dependency array usage
- Cleanup functions
- Simple React examples

## 🛠️ Technologies Used

- React
- JavaScript (ES6+)
- HTML
- CSS
- Parcel


## 📚 Learning Outcome

By completing this project, you'll understand how to use `useEffect` for handling side effects, controlling component updates, and writing cleaner, more efficient React applications.
