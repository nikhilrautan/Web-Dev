# 🚀 Full Stack Web Development Journey

This repository documents my journey through Full Stack Web Development. It covers everything from frontend fundamentals to backend development, databases, and deployment.

## 📚 Tech Stack & Concepts Covered

### 🎨 Frontend
- **HTML5** – Semantic structure, forms, accessibility
- **CSS3** – Flexbox, Grid, responsive design, animations
- **JavaScript (ES6+)** – DOM manipulation, closures, async/await, promises, event loop
- **React.js** – Components, hooks (useState, useEffect, useContext, useRef), routing, state management

### ⚙️ Backend
- **Node.js** – Runtime fundamentals, modules, file system, event-driven architecture
- **Express.js** – REST APIs, middleware, routing, error handling
- **Authentication** – JWT, sessions, cookies, password hashing (bcrypt)

### 🗄️ Database
- **MongoDB** – NoSQL data modeling, CRUD operations
- **Mongoose** – Schemas, models, aggregation pipelines, relationships

### 🛠️ Tools & Practices
- **Git & GitHub** – Version control, branching, collaboration
- **Postman** – API testing
- **Environment variables & config management**
- **Deployment** – Hosting frontend and backend apps
